# Canopy v2.1 — Wiseland Studio

داشبورد کاربردی جنگو با هویت سبز `#0A1F17` و طلایی `#C9A45A`، فارسی، راست‌به‌چپ، فونت محلی وزیرمتن، حالت روشن و تیره و اسکرول‌های طلایی.

![داشبورد](screenshots/dashboard-light.png)

## امکانات واقعی

- **اسکرول مستقل:** در حالت فارسی، اسکرول لبه راست برای منو و اسکرول چسبیده به مرز منو برای وسط صفحه است؛ نوار بالا ثابت می‌ماند.
- **کانبان:** نمای ستونی پروژه‌ها، جابه‌جایی با کشیدن کارت یا فرم وضعیت، صفحه‌بندی مستقل ستون‌ها و جلوگیری از بازنویسی وضعیت قدیمی.
- **عملیات گروهی:** انتخاب رکوردهای صفحه، تکمیل و بازگشایی کارها، تعیین مسئول گروهی و ثبت پرداخت گروهی صورتحساب‌ها.
- **یادداشت پروژه:** گفتگوی داخلی اعضای همان پروژه، اعلان یادداشت جدید و حذف یادداشت با کنترل نویسنده و مجوز.
- **جستجوی سراسری:** جستجوی پروژه، صورتحساب، کار، هزینه و رویداد؛ یادداشت و پیام خصوصی وارد نتایج عمومی نمی‌شوند.
- **خروجی گزارش مالی:** CSV درآمد، هزینه و خالص واقعی هر ماه در بازه انتخاب‌شده.

- **پروژه:** ثبت، ویرایش، حذف با تأیید، جزئیات، اعضای واقعی تیم، توضیحات، بودجه و پیشرفت.
- **صورتحساب:** ثبت و ویرایش، تاریخ صدور و پرداخت، مهلت، ارتباط با پروژه، ثبت پرداخت، چاپ و ذخیره PDF از مرورگر، خروجی CSV با اعمال فیلترها.
- **هزینه:** ثبت و ویرایش هزینه، مبلغ، تاریخ، دسته‌بندی و پروژه؛ ورود مستقیم به گزارش مالی.
- **کار:** تعیین مسئول، اولویت، موعد، ارتباط با پروژه، تکمیل و بازگشایی.
- **گزارش:** درآمد، هزینه و خالص واقعی در بازه‌های ۳، ۶ و ۱۲ ماهه، مقایسه با بازه قبل و ترکیب پروژه‌ها بر اساس دسته‌بندی واقعی.
- **تقویم:** تعداد روزهای واقعی ماه، جابه‌جایی بین ماه‌ها، رویداد چندروزه و موعد پروژه‌ها و کارها.
- **پیام خصوصی:** ذخیره در دیتابیس بین کاربران واقعی، تاریخچه، وضعیت خواندن، دریافت پیام جدید با بررسی هر ۵ ثانیه.
- **اعلان:** پیام جدید، کار اختصاص‌یافته و تغییر پروژه و رویداد؛ خواندن تکی یا همه.
- **تیم:** اعضای واقعی، نقش، تعداد پروژه و کار باز هر عضو، ورود به مدیریت کاربران و مجوزها.
- **حساب:** نام و ایمیل، تغییر رمز و ذخیره تم و جهت چیدمان روی حساب کاربر.
- **ادمین:** کارت‌های آمار زنده، ظاهر هماهنگ با برند، مدیریت مدل‌ها و کاربران و گروه‌ها.
- جستجو، فیلتر، مرتب‌سازی، صفحه‌بندی و ثبت سابقه تغییرات در داشبورد.

همه اعداد تجاری از دیتابیس محاسبه می‌شوند. بدون رکورد، عدد صفر یا حالت خالی نمایش داده می‌شود؛ درصد رشد وقتی درآمد دوره قبل صفر باشد، ساخته نمی‌شود. تصویرها و رابط هیچ درآمد، عضو تیم یا رویداد از پیش‌ساخته‌ای ندارند.

## نصب

Python نسخه ۳٫۱۲ یا جدیدتر لازم است:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

در لینوکس و مک، محیط مجازی را با `source .venv/bin/activate` فعال کنید.

- داشبورد: http://127.0.0.1:8000/
- ادمین: http://127.0.0.1:8000/admin/
- ورود: http://127.0.0.1:8000/accounts/login/

بسته سورس دیتابیس یا نام کاربری و رمز پیش‌فرض ندارد. حساب خودتان را بسازید، وارد شوید و اطلاعات واقعی ثبت کنید.

## ارتقا و داده‌های قبلی

قبل از ارتقا از دیتابیس بکاپ بگیرید و سپس `python manage.py migrate` را اجرا کنید. اطلاعات قبلی حفظ می‌شوند. برای صورتحساب‌های پرداخت‌شده قدیمی که تاریخ پرداخت ندارند، گزارش از تاریخ صدور استفاده می‌کند؛ می‌توانید تاریخ واقعی پرداخت را در فرم ویرایش وارد کنید.

`seed_demo` صرفاً دستور اختیاری افزودن مثال است و در نصب عادی لازم نیست. `clear_demo` رکوردهای دست‌نخورده نمونه نسخه اول را حذف می‌کند؛ حساب‌ها و اطلاعات شخصی حفظ می‌شوند. پروژه نمونه‌ای که داده جدید به آن متصل شده باشد حذف نمی‌شود.

## مبنای محاسبات

درآمد وصول‌شده جمع صورتحساب‌های پرداخت‌شده و مانده، جمع صورتحساب‌های در انتظار است. نمودار درآمد بر اساس تاریخ پرداخت و هزینه بر اساس تاریخ ثبت هزینه محاسبه می‌شود. خالص درآمد، اختلاف درآمد و هزینه در بازه انتخاب‌شده است. درصد دسته‌بندی‌ها از تعداد واقعی پروژه‌ها به دست می‌آید.

مبالغ **تومان**، تاریخ‌ها **میلادی** و ساعت رویدادها **تهران** هستند. ثبت پرداخت فقط دفتر مالی برنامه را به‌روز می‌کند و تراکنش بانکی ایجاد نمی‌کند. تغییر جهت چیدمان ترجمه انگلیسی نیست.

## دسترسی‌ها

نمای کلی و فهرست‌ها طبق طراحی داشبورد عمومی در دسترس‌اند. پیام خصوصی، اعلان، تیم و تنظیمات نیازمند ورود هستند. هر کاربر فقط گفتگوهای خودش را می‌بیند.

برای ایجاد، تغییر و حذف رکوردها مجوزهای مدل جنگو لازم‌اند؛ مثلاً `dashboard.add_project`، `dashboard.change_invoice` و `dashboard.delete_event`. ابرکاربر همه مجوزها را دارد. مجوز اعضا و گروه‌ها را در ادمین تنظیم کنید. کاربران جدید از فرم استاندارد مدیریت جنگو اضافه می‌شوند.

این برنامه یک فضای کاری مشترک است. اگر اطلاعات محرمانه شرکت روی آن قرار می‌دهید، برای صفحه‌های خواندن و خروجی CSV ورود اجباری و فیلتر سازمان یا مالک را مطابق نیاز خود اضافه کنید. پیام‌های خصوصی در فهرست مدل‌های ادمین ثبت نشده‌اند.

## تست و اسکرین‌شات

```bash
python manage.py check
python manage.py makemigrations --check --dry-run
python manage.py test
```

تست‌ها محاسبات واقعی، دیتابیس خالی، ماه کبیسه، رویداد چندروزه، عملیات ثبت و ویرایش و حذف، مجوزها، حریم پیام، اعتبارسنجی فرم، فیلتر و صفحه‌بندی، تغییر رمز و تنظیمات را بررسی می‌کنند.

برای تولید دوباره ۱۱ اسکرین‌شات واقعی، Chrome را نصب کنید و با سرور محلی روشن اجرا کنید:

```bash
python -m pip install -r requirements-dev.txt
python tools/screenshots.py
```

ابزار حساب‌های موقت و پیام آزمایشی می‌سازد، ذخیره واقعی پیام و تنظیمات و نمایش موبایل را بررسی می‌کند و پس از اتمام آن‌ها را حذف می‌کند. روی دیتابیس توسعه اجرا کنید. متغیرهای `CHROME_PATH` و `SCREENSHOT_URL` اختیاری هستند.

## شخصی‌سازی و انتشار

رنگ‌های داشبورد در `static/css/canopy.css` و ظاهر ادمین در `static/css/admin.css` قرار دارند. محاسبات مالی و تقویم در `dashboard/services.py` متمرکز هستند. صفحات به قالب‌های جزئی قابل استفاده مجدد تقسیم شده‌اند.

متغیرهای `DJANGO_DEBUG`، `DJANGO_SECRET_KEY` و `DJANGO_ALLOWED_HOSTS` از محیط سیستم خوانده می‌شوند؛ `.env` خودکار بارگذاری نمی‌شود. برای میزبانی عملیاتی debug را خاموش کنید، کلید مستقل و دامنه‌های مجاز را تنظیم کنید، WSGI و HTTPS و فایل‌های استاتیک را آماده کنید و `collectstatic` و `check --deploy` را اجرا کنید.

ساخت بسته:

```bash
python tools/package.py
```

فایل `dist/canopy-wiseland-studio-v2.1.0.zip` شامل کد، تست، تصاویر، مستندات و دارایی‌ها ساخته می‌شود؛ دیتابیس، بکاپ، رمزها و محیط مجازی در آن قرار نمی‌گیرند.
